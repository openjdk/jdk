This directory contains wrappers for using the AOT workflow to execute
a subset of the tests  ../../../../../../jdk/java/lang/invoke.

Note that the name of the wrapper is the same as the original test. E.g.,

- the wrapper: ./BigArityTest.java
- original test: ../../../../../../jdk/java/lang/invoke/BigArityTest.java

However, the wrapper class is in the default package, whereas the original test
is in the test.java.lang.invoke package.

Some of the wrappers are auto-generated by CDSMHTest_generate.sh. Other wrappers
are hand written.
